CCS 117

Fundamentals of Computing

TOPIC 1: INTRODUCTION TO COMPUTERS

1.1 Definition of a Computer

A computer is an electronic device that accepts data as input, processes the data according to instructions, stores information, and produces useful output.

1.2 Basic Functions of a Computer

  1. Input: Receiving data using devices such as keyboards and mice.
  2. Processing: Performing operations on the data.
  3. Output: Presenting processed information.
  4. Storage: Saving data and information for future use.

1.3 Data and Information

Data: Raw facts that have not yet been processed.

Information: Data that has been processed into a meaningful form.

Example:
Data: 60, 70, 80
Information: The average mark is 70.

1.4 Characteristics of Computers

  • Speed
  • Accuracy
  • Reliability
  • Large storage capacity
  • Versatility
  • Automation

1.5 Limitations of Computers

  • They depend on instructions and data.
  • They require electricity or another power source.
  • Incorrect instructions can produce incorrect results.
  • They do not independently think like human beings.

TOPIC 2: CLASSIFICATION OF COMPUTERS

2.1 According to Data Processing

  • Analog computers: Process continuous data.
  • Digital computers: Process discrete data, commonly represented in binary.
  • Hybrid computers: Combine analog and digital features.

2.2 According to Size and Processing Capacity

  • Supercomputers
  • Mainframe computers
  • Minicomputers
  • Microcomputers

TOPIC 3: COMPUTER HARDWARE

Hardware refers to the physical components of a computer that can be seen and touched.

  • Input devices: Keyboard, mouse and scanner.
  • Output devices: Monitor, printer and speakers.
  • Processing devices: Central Processing Unit (CPU).
  • Storage devices: Hard disk, SSD and flash drive.

TOPIC 4: COMPUTER SOFTWARE

Software refers to programs and instructions that tell a computer what to do.

4.1 System Software

Software that manages computer hardware and provides a platform for applications. Examples include operating systems and device drivers.

4.2 Application Software

Software designed to help users perform specific tasks. Examples include word processors, spreadsheets and web browsers.

TOPIC 5: COMPUTER MEMORY AND STORAGE

  • RAM: Temporary working memory that is normally volatile.
  • ROM: Non-volatile memory used to store firmware.
  • Cache: High-speed memory that helps the CPU access frequently used data.
  • Secondary storage: Long-term storage such as hard drives and SSDs.

TOPIC 6: NUMBER SYSTEMS

A number system is a method of representing numbers using a set of symbols and a base.

  • Binary: Base 2, digits 0 and 1.
  • Octal: Base 8, digits 0 to 7.
  • Decimal: Base 10, digits 0 to 9.
  • Hexadecimal: Base 16, digits 0 to 9 and A to F.

TOPIC 7: OPERATING SYSTEMS

An operating system is system software that manages computer hardware and software resources.

Examples: Windows, Linux, macOS and Android.

Functions of an Operating System

  • Memory management
  • File management
  • Process management
  • Device management
  • Security management
  • Providing a user interface

TOPIC 8: COMPUTER NETWORKS AND THE INTERNET

A computer network is a group of connected computers and devices that communicate and share resources.

  • LAN: Local Area Network.
  • MAN: Metropolitan Area Network.
  • WAN: Wide Area Network.

The Internet is a worldwide network of interconnected computer networks.

TOPIC 9: COMPUTER SECURITY AND ETHICS

Computer security involves protecting computer systems, networks and information from unauthorized access, damage or misuse.

  • Malware and computer viruses
  • Phishing
  • Password security
  • Data privacy
  • Data backups
  • Responsible use of computers

  4. List five characteristics of computers.
  5. Explain the difference between hardware and software.
  6. Differentiate between RAM and ROM.
  7. State the bases of binary, octal, decimal and hexadecimal.
  8. Explain four functions of an operating system.
  9. Differentiate between LAN, MAN and WAN.
  10. Explain five ways of protecting computer information.

REVISION ANSWERS

  1. An electronic device that accepts, processes, stores and outputs data.
  2. Input, processing, output and storage.
  3. Data is raw facts; information is processed, meaningful data.
  4. Speed, accuracy, reliability, storage and versatility.
  5. Hardware is physical; software consists of programs and instructions.
  6. RAM is normally volatile; ROM is non-volatile.
  7. Binary: 2; Octal: 8; Decimal: 10; Hexadecimal: 16.
  8. Memory, file, process and device management.
  9. LAN covers a local area; MAN covers a metropolitan area; WAN covers a wide geographical area.
  10. Use strong passwords, backups, security software, updates and careful handling of personal information.
