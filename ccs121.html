INTRODUCTION TO PROGRAMMING

Pascal Programming Language - Study Notes

1. Introduction to Programming

1.1 Meaning of Programming

Programming is the process of writing instructions that tell a computer how to perform a particular task. These instructions are written using a programming language.

1.2 What is a Program?

A program is a sequence of instructions written to enable a computer to solve a problem or perform a specific task.

1.3 What is Pascal?

Pascal is a high-level, structured programming language developed by Niklaus Wirth. It is commonly used for teaching programming concepts such as variables, control structures, procedures, functions and arrays.

1.4 Characteristics of Pascal

  • It is a high-level programming language.
  • It supports structured programming.
  • It uses clearly defined data types.
  • It supports procedures and functions.
  • It supports arrays and other data structures.
  • Its syntax encourages organized programs.

2. Structure of a Pascal Program

A Pascal program follows a structured arrangement of declarations and instructions.

Example

program HelloWorld;

begin
    writeln('Hello World');
end.

Explanation

  • program HelloWorld; - Gives the program its name.
  • begin - Marks the beginning of the main program block.
  • writeln - Displays information and moves to a new line.
  • end. - Marks the end of the program.
Remember: The full stop after the final end. marks the end of a Pascal program.

3. Variables and Constants

3.1 Variables

A variable is a named memory location used to store data. Its value can change while a program is running.

Variable declaration

var
    age: integer;
    name: string;
    marks: real;

3.2 Constants

A constant is a named value that does not change during normal program execution. 

const
    Pi = 3.142;
    University = 'Maseno University';

3.3 Rules for Naming Variables

  • A name should begin with a letter.
  • It should not contain spaces.
  • It should not be a reserved Pascal keyword.
  • Use meaningful names.

4. Data Types in Pascal

A data type determines the kind of value that a variable can store.

Data type Description Example
Integer Whole numbers 25, -10
Real Numbers with decimal parts 12.5, 3.14
Char A single character 'A', 'B'
String A sequence of characters 'Pascal'
Boolean Logical values True, False

Example

var
    age: integer;
    average: real;
    grade: char;
    passed: boolean;

begin
    age := 20;
    average := 75.5;
    grade := 'A';
    passed := true;
end.
The assignment operator in Pascal is :=. For example, age := 20; assigns 20 to age.

5. Input and Output Statements

5.1 Output using Write and Writeln

The write and writeln statements display information on the screen. 

begin
    write('Welcome');
    writeln(' to Pascal programming');
end.

5.2 Input using Read and Readln

The read and readln statements receive information entered by the user. 

program StudentAge;

var
    age: integer;

begin
    writeln('Enter your age:');
    readln(age);

    writeln('Your age is ', age);
end.

Operators are symbols used to perform calculations, comparisons and logical operations.

6.1 Arithmetic Operators

Operator Meaning Example

*Multiplication5 * 3 = 15

6.2 Relational Operators

  • = Equal to
  • <> Not equal to

  • > Greater than
  • <= Less than or equal to
  • >= Greater than or equal to

6.3 Logical Operators

  • and - True when both conditions are true.
  • or - True when at least one condition is true.
  • not - Reverses a logical value.

7. Control Structures

Control structures determine the order in which instructions are executed in a program.

7.1 Sequence

Instructions are executed one after another in the order in which they appear.

7.2 Selection - If Statement

program CheckAge;

var
    age: integer;

begin
    writeln('Enter age:');
    readln(age);

    if age >= 18 then
        writeln('Adult')
    else
        writeln('Below 18');
end.

7.3 Case Statement

program GradeChoice;

var
    grade: char;

begin
    writeln('Enter grade:');
    readln(grade);

    case grade of
        'A': writeln('Excellent');
        'B': writeln('Very Good');
        'C': writeln('Good');
    else
        writeln('Other grade');
    end;
end.

7.4 Repetition - For Loop

program Counting;

var
    i: integer;

begin
    for i := 1 to 5 do
        writeln(i);
end.

7.5 While Loop

program WhileExample;

var
    i: integer;

begin
    i := 1;

    while i <= 5 do
    begin
        writeln(i);
        i := i + 1;
    end;
end.

7.6 Repeat Until Loop

program RepeatExample;

var
    i: integer;

begin
    i := 1;

    repeat
        writeln(i);
        i := i + 1;
    until i > 5;
end.

8. Arrays in Pascal

Important topic: Arrays allow a programmer to store several values of the same data type under one variable name.

8.1 Definition of an Array

An array is a collection of elements of the same data type, stored under one identifier and accessed using index values.

8.2 Why Arrays Are Used

  • To store many related values.
  • To reduce the number of separate variables.
  • To make processing of data easier.
  • To make sorting and searching easier.

8.3 Declaring an Array

var
    marks: array[1..5] of integer;

Explanation:

  • marks is the array name.
  • 1..5 specifies the index range.
  • integer specifies the data type.

This declaration creates five integer elements: marks[1], marks[2], marks[3], marks[4] and marks[5].

8.4 Assigning Values to Array Elements

program ArrayExample;

var
    marks: array[1..5] of integer;

begin
    marks[1] := 70;
    marks[2] := 65;
    marks[3] := 80;
    marks[4] := 55;
    marks[5] := 90;

    writeln(marks[1]);
end.

8.5 Accessing Array Elements Using a Loop

program DisplayMarks;

var
    marks: array[1..5] of integer;
    i: integer;

begin
    for i := 1 to 5 do
    begin
        writeln('Enter mark:');
        readln(marks[i]);
    end;

    writeln('The marks are:');

    for i := 1 to 5 do
        writeln(marks[i]);
end.

8.6 Finding the Sum of Array Elements

program SumArray;

var
    numbers: array[1..5] of integer;
    i, total: integer;

begin
    total := 0;

    for i := 1 to 5 do
    begin
        writeln('Enter a number:');
        readln(numbers[i]);

        total := total + numbers[i];
    end;

    writeln('Sum = ', total);
end.

Explanation:

  1. An array named numbers is declared.
  2. The variable total is initialized to zero.
  3. A loop accepts five numbers.
  4. Each number is added to total.
  5. The final sum is displayed.

8.7 Finding the Average of Array Elements

program AverageArray;

var
    numbers: array[1..5] of real;
    i: integer;
    total, average: real;

begin
    total := 0;

    for i := 1 to 5 do
    begin
        writeln('Enter a number:');
        readln(numbers[i]);

        total := total + numbers[i];
    end;

    average := total / 5;

    writeln('Average = ', average:0:2);
end.

8.8 Finding the Largest Element

program LargestNumber;

var
    numbers: array[1..5] of integer;
    i, largest: integer;

begin
    for i := 1 to 5 do
    begin
        writeln('Enter a number:');
        readln(numbers[i]);
    end;

    largest := numbers[1];

    for i := 2 to 5 do
    begin
        if numbers[i] > largest then
            largest := numbers[i];
    end;

    writeln('Largest number = ', largest);
end.

8.9 One-Dimensional Arrays

A one-dimensional array stores elements in a single sequence. Each element is accessed using one index. 

var
    ages: array[1..10] of integer;

8.10 Two-Dimensional Arrays

A two-dimensional array stores data in rows and columns. It uses two indices to access an element. 

var
    matrix: array[1..3, 1..3] of integer;

For example:

matrix[1,1] := 10;
matrix[1,2] := 20;
matrix[2,1] := 30;

8.11 Traversing a Two-Dimensional Array

program MatrixInput;

var
    matrix: array[1..3, 1..3] of integer;
    i, j: integer;

begin
    for i := 1 to 3 do
    begin
        for j := 1 to 3 do
        begin
            writeln('Enter an element:');
            readln(matrix[i,j]);
        end;
    end;

    for i := 1 to 3 do
    begin
        for j := 1 to 3 do
            write(matrix[i,j], ' ');

        writeln;
    end;
end.

8.12 Important Array Terms

  • Element: An individual value stored in an array.
  • Index: The position used to access an element.
  • Subscript: The index expression identifying an element.
  • Traversal: Visiting array elements one by one.
  • Array bounds: The permitted range of index values.
Important: Accessing an index outside the declared array bounds is an error. For example, an array declared as array[1..5] should not be accessed using marks[6].

9. Procedures and Functions

9.1 Procedures

A procedure is a named block of code that performs a particular task. It does not return a value as its result. 

program ProcedureExample;

procedure Greet;
begin
    writeln('Welcome to Pascal');
end;

begin
    Greet;
end.

9.2 Functions

A function is a named block of code that performs a task and returns a value. 

program FunctionExample;

function Add(a, b: integer): integer;
begin
    Add := a + b;
end;

begin
    writeln(Add(5, 3));
end.

Difference Between Procedures and Functions

Procedure Function
Performs a task. Performs a task and returns a value.
Does not have a return type. Has a declared return type.
Called as a statement. Can be used in expressions.

11. Selected Answers

Question 1: Difference between div and mod

17 div 5 = 3
17 mod 5 = 2

div gives the integer quotient, while mod gives the remainder.

Question 2: Check whether a number is even or odd

program EvenOdd;

var
    number: integer;

begin
    writeln('Enter a number:');
    readln(number);

    if number mod 2 = 0 then
        writeln('Even number')
    else
        writeln('Odd number');
end.

Question 3: Display numbers from 1 to 20

program DisplayNumbers;

    i: integer;

begin
    for i := 1 to 20 do
        writeln(i);
end.
